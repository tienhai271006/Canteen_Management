# web_client

Giao diện khách hàng (React + Vite): đăng ký, đăng nhập, xem thực đơn, giỏ hàng, đặt đơn, theo dõi đơn vừa đặt.

```
cd web_client
npm install
npm run dev        # http://localhost:5173, tự chuyển /api sang http://localhost:8080
```
Chạy server Spring Boot trước (`mvn spring-boot:run` trong `server/`). Tài khoản mẫu ở profile dev: `sv@phenikaa-uni.edu.vn` / `Canteen@123`.

Chưa có: khu vực quầy (vendor) và admin.
